This is a basic re-implementation of the classic Frogger arcade game, written in C++ using the SDL2 library. The player controls a frog trying to cross a busy road and a hazardous river to reach the top of the screen without losing all lives. Cars, logs, and other obstacles move across the screen.

**Controls**

Arrow Keys / WASD → Move the frog one space in that direction

**Notes**

Built with SDL2 for graphics, input, and timing.
